越南冒險日記｜PWA 部署準備包

檔案：
- index.html：旅遊網站
- manifest.webmanifest：加入主畫面設定
- service-worker.js：快取網站核心檔案，支援離線重新開啟
- icon.svg：網站圖示

重要：
1. 這個套件是「PWA 部署準備包」，不是已上線網站。
2. 必須部署到 HTTPS 網址（例如 GitHub Pages 等靜態網站服務），Service Worker 才會正常工作；localhost 是開發例外。
3. 上線後，先用 Android Chrome 開啟網址，等待首次載入完成，再選「加入主畫面」或「安裝應用程式」。
4. 安裝後先開啟一次，確認行程等頁面正常；接著開飛航模式重新開啟測試。
5. 記帳使用瀏覽器本機儲存。清除網站資料、換瀏覽器或換手機可能遺失資料，請定期使用網站內的「匯出網站資料備份」。
6. 行程中的時間與地址仍須以最新電子票、訂房憑證及業者通知核對。
